Zomato Dashboard – Power BI Description

This Zomato Dashboard provides comprehensive insights into food delivery performance, customer behavior, and restaurant trends using interactive data visualizations. The dashboard helps stakeholders understand ordering patterns, revenue drivers, and service efficiency across locations.

🔍 Key Metrics & Insights

Total orders, total revenue, and average order value

Orders by city, restaurant, and cuisine

Top-performing restaurants and cuisines

Order trends by time (day/hour)

Delivery time analysis

Customer ratings and reviews summary

📈 Dashboard Features

KPI cards for quick performance overview

Interactive filters for city, cuisine, restaurant, and date

Trend analysis for order volume and revenue

Visual breakdown of customer preferences

Clean and user-friendly dashboard design

🛠 Tools Used

Power BI

Power Query for data cleaning and transformation

DAX for calculated measures

💼 Business Value

This dashboard enables:

Identification of high-demand cuisines and locations

Performance monitoring of restaurants and delivery efficiency

Optimization of delivery times and resource allocation

Data-driven decision-making for promotions and partnerships
